IGCSEMYSG RESOURCE MANAGEMENT GUIDE
====================================

You normally edit only resources-data.js. The page design, search, filters and
sorting are controlled by resources.js.


1. CREATE RESOURCE FOLDERS ON GITHUB
------------------------------------

In the repository root, create resources/ and one folder per subject:

resources/mathematics/
resources/additional-mathematics/
resources/physics/
resources/english-first-language/

You may organise a larger subject into topic folders:

resources/mathematics/algebra/
resources/mathematics/geometry/

Use short lowercase filenames with hyphens and no spaces:

resources/mathematics/algebra/linear-equations-notes.pdf


2. UPLOAD THE FILE FIRST
------------------------

A. Open the correct resources/subject/topic folder on GitHub.
B. Select Add file > Upload files.
C. Drag in the PDF or permitted file and commit it.
D. Open it once and confirm its path.

Do not publish a catalogue entry before its file exists.


3. ADD ITS CATALOGUE ENTRY
--------------------------

Open resources-data.js and paste an object inside:

window.IGCSEMYSG_RESOURCES = [
  // paste entries here
];

Complete example:

  {
    id: "mathematics-linear-equations-notes",
    title: "Linear equations revision notes",
    subject: "Mathematics",
    type: "Revision notes",
    board: "Cambridge IGCSE",
    syllabusCode: "0580",
    topics: ["Algebra", "Linear equations"],
    level: "Year 10–11",
    publishedDate: "2026-08-14",
    updatedDate: "2026-08-14",
    description: "Concise notes covering methods, worked examples and common errors.",
    url: "resources/mathematics/algebra/linear-equations-notes.pdf",
    fileSize: "1.8 MB",
    featured: true,
    published: true,
    order: 10
  },

Add a comma between entries. The final entry may also have a comma.


4. FIELD REFERENCE
------------------

id
  Permanent unique identifier. Use lowercase letters and hyphens.

title
  Main title displayed on the card. Keep it specific and useful.

subject
  Controls the Subject filter. It must exactly match a subject listed inside
  window.IGCSEMYSG_SUBJECTS.

type
  Controls the Resource type filter. Use a type from
  window.IGCSEMYSG_RESOURCE_TYPES.

board
  Controls the Exam board filter. Use a board from
  window.IGCSEMYSG_EXAM_BOARDS.

syllabusCode
  Optional. Examples: "0580", "0625" or "4MA1". Omit this line if irrelevant.

topics
  Optional searchable labels, for example:
  topics: ["Algebra", "Simultaneous equations"]
  Three appear on the card; additional topics remain searchable.

level
  Optional. Examples: "Year 10–11", "Core", "Extended", "Foundation" or
  "Higher".

publishedDate
  Use YYYY-MM-DD. This supports Newest first sorting.

updatedDate
  Optional. Change it only after a meaningful revision. When present, it is the
  date displayed and used by Newest first.

description
  One concise sentence explaining the contents and purpose.

url
  Relative repository file path or complete https address.

fileSize
  Optional display detail such as "1.8 MB", "12 pages" or "Web guide".

featured
  true places the item before ordinary resources in Recommended order. Use it
  selectively.

published
  true shows the resource. false hides it without deleting the entry.

order
  Controls Recommended order after featured status. Lower numbers appear first.
  Use gaps such as 10, 20 and 30 so you can insert resources later.


5. OTHER RESOURCE EXAMPLES
--------------------------

Topical questions:

  {
    id: "physics-forces-topical-questions-01",
    title: "Forces and motion: topical questions",
    subject: "Physics",
    type: "Topical questions",
    board: "Cambridge IGCSE",
    syllabusCode: "0625",
    topics: ["Forces", "Motion", "Graphs"],
    level: "Extended",
    publishedDate: "2026-08-14",
    description: "Focused examination-style questions on forces, motion and graph interpretation.",
    url: "resources/physics/forces/forces-topical-questions-01.pdf",
    fileSize: "10 pages",
    featured: false,
    published: true,
    order: 20
  },

External textbook or official link:

  {
    id: "biology-official-syllabus-link",
    title: "Biology syllabus information",
    subject: "Biology",
    type: "Textbook link",
    board: "Cambridge IGCSE",
    syllabusCode: "0610",
    topics: ["Syllabus"],
    publishedDate: "2026-08-14",
    description: "Open the official publisher or examination-board information.",
    url: "https://example.com/official-page",
    fileSize: "External website",
    featured: false,
    published: true,
    order: 30
  },

External links automatically open in a new tab.


6. ADD A SUBJECT, TYPE OR BOARD
-------------------------------

Add the new value to IGCSEMYSG_SUBJECTS, IGCSEMYSG_RESOURCE_TYPES or
IGCSEMYSG_EXAM_BOARDS near the top of resources-data.js. Use exactly the same
spelling in resource entries.


7. ARRANGE RESOURCES
--------------------

The page offers:

- Recommended: featured items first, followed by order.
- Newest first: updatedDate, otherwise publishedDate.
- Title A–Z: alphabetical title.

A useful learning sequence is:

10  Foundational notes
20  Guided examples
30  Topical questions
40  Model answers
50  Exam guide


8. COPYRIGHT AND ACCESS
-----------------------

Only upload files IGCSEMYSG owns, created, licensed or has permission to share.
Do not upload copyrighted textbooks, restricted papers or paid third-party
material without permission.

Do not put paid member files in the public GitHub repository. A visual lock is
not security. Store protected materials inside the authenticated app or private
storage with access controls.


9. TEST EVERY UPDATE
--------------------

1. Open resources.html.
2. Search by part of the title and by a topic.
3. Test the subject, type and board filters.
4. Test Recommended, Newest and Title arrangements.
5. Open the resource and confirm the correct file loads.
6. Test once on a phone.
7. Confirm unpublished entries do not appear.
8. Confirm the membership button reaches the pricing page.
